# Support and maintenance

Protspect is maintained through the Biomolecular Systems Modeling and Design
Group's [repository](https://github.com/biomodsquad/protein-sequence-spectral-analysis).
The public contact channel is
[GitHub Issues](https://github.com/biomodsquad/protein-sequence-spectral-analysis/issues).

When requesting help, include the package and Python versions, OS, dependency
versions, a minimal example, the full traceback, and expected versus observed
behavior. Use synthetic sequences if real sequences are private. For feature
differences, include the embedding, FFT length, normalization, centering,
channel standardization, and feature selector.

The current release candidate is an alpha. Support focuses on the latest
release and the development branch; there is no long-term maintenance promise
for older alpha releases or guaranteed response time. Supported environment
targets and completed checks are listed in
[docs/COMPATIBILITY.md](docs/COMPATIBILITY.md). Numerical corrections and API
changes are recorded in [CHANGELOG.md](CHANGELOG.md).

Report suspected vulnerabilities using GitHub's private vulnerability reporting
feature if it is enabled for the repository. Do not include credentials or
private sequence data in public reports.
